# waterandearth

Static house-build cost app.

## Features

- Simple visual cost cards
- Planned, paid, and left-to-pay totals
- Category cards for each part of the house
- Quick add/edit cost modal
- Local browser save
- JSON backup and restore
- Excel `.xls` export
- English and Vietnamese interface
- PWA manifest and service worker for install/offline support

## Deploy

Upload these files as the `waterandearth` site/app:

- `index.html`
- `manifest.json`
- `service-worker.js`
- `assets/icon.svg`

Any static host works, including Netlify, Vercel static hosting, GitHub Pages, S3, or a basic web server.
